# 研究方案：本体约束的多专家处理响应融合

## 1. 课题定位
建议题目：**面向未知后处理的本体约束多专家响应融合语音鉴伪**。
工作名OntoResponse不代表已注册名称或新颖性保证。
输入整条录音，输出一个真假logit/校准后概率。TTS、VC及语音克隆作为spoof；真人来源的常规轻度编码、滤波和噪声不改变来源标签。语义事实真假、授权、重放、局部编辑定位、身份验证与生成器唯一归因不纳入第一篇。

总体目标始终是更准确地综合证据判别真假。模型一致错误是分析子问题，不能把主方法退回风险加权。

## 2. 核心科学问题
**在固定多专家和相同观测预算下，受控后处理引起的表征/分数响应，是否提供可迁移的真假判别信息；如何利用“来源—前后对应—同处理—同家族”关系，使该信息比普通拼接更有效地泛化到未知处理条件？**

三个可证伪假设：
- H1 观测价值：原始embedding/分数 + 响应，比原始embedding/分数更有判别力。必须与多视图平均、拼接、单最强专家+探针对照。
- H2 结构价值：相同观测与元信息下，正确关系优于普通MLP、无类型消息传递或Set Transformer及错误关系。
- H3 泛化价值：改进在未见后处理和独立来源上保留，且不显著损害无新增处理性能。

响应是对同一波形增加计算而得到的观测，不是增加独立采集的声学信号。类型化关系在固定配置下也是已知结构，可能提供归纳偏置/样本效率，不提供凭空新增的真假信息。

## 3. 为什么可能有效
1. 最终单分数压缩了表征信息；分类前embedding允许后端融合重新判别。
2. 已知操作提供参照：把“某个向量异常”转化为“同一模型对同一操作前后的变化”。
3. 不同专家在相同操作下的响应可能互补；共享类型参数可减少对具体专家-参数组合的过拟合。
4. 原始分支保留，避免处理破坏痕迹后只剩无用响应。
5. 全部观测可以离线缓存；轻量关系网络直接用真假监督，实施成本可控。

以上都是机制假设而非效果结论。网络结构不能确保噪声不变性、因果可识别性或未知域保证。

## 4. 已有工作与创新边界
S01/S02/S03提供真实鉴伪专家与表征；S07 RawBoost已研究数据增强；S08 RAPTOR已研究测试时扰动与模型融合/不确定性；S09 ARPN已使用扰动和差异分析；S10 R-GCN提供多关系计算；S11 Set Transformer提供无显式本体的强集合对照。
因此不能声称首先使用多专家、embedding、扰动、图网络、语义分组或辅助概率校准。

候选贡献：
A. 可执行的处理响应证据模式：输入、操作、before/after、模型与派生关系经过校验，直接编译数值邻接。
B. 三种互补对应关系的类型化判别：同专家before/after、同操作跨专家、同家族不同参数；原始分支 + 响应分支端到端训练轻量分类器。
C. 分离更多观测/显式差分/类型约束/额外算力贡献的评测协议，含未知处理、错误分组与配对统计。

本体应称为“轻量取证测量/操作本体”，不冒称完整语音生成机制本体。其算法贡献成立，必须由H2验证；只导出RDF没有数值作用不算。

## 5. 最小与正式配置
- 工程联调：2专家、4探针、少量真实录音；结果只检查接口。
- 最小研究：3专家、6探针（3家族×2参数），1个训练来源+受控未知处理+外部测试。
- 专家起点：AASIST、SSL+AASIST、RawNet2。选择是可复现起点而非最强/SOTA承诺。若第三专家无增量价值，在训练/开发阶段调整，不能看最终test后挑专家。
- 诊断操作：带宽、轻度噪声、传统有损编码。每家族2个实例以检验参数趋势及真正的成员重分组。
- 主模型：每专家适配 → 原始和响应token → 2层类型化均值消息传递 → 原始/响应分开池化 → MLP logit。默认只用BCE，不堆对比、域对抗、生成器预测损失。

## 6. 阶段门
P0 资源与协议：真实权重、原生输出、划分、score方向、探针合法性可核验。
P1 信息可行性：在开发数据比较分数、embedding、处理响应；观察分组错误，但不预设结果。
P2 结构可行性：相同信息强基线 vs typed模型；先做受控未知处理的开发折。
P3 正式研究：冻结假设、主指标、所有holdout、调参预算；多随机种子；开封最终test。

停止/调整条件：
- 响应对强原始基线毫无增益：检验探针是否太弱/太强、裁剪噪声、原模型质量；不靠加深GNN掩盖。
- richer input有益但typed≈untyped：研究成果定位为响应融合，不声称本体增益。
- 只有新参数强度有效：只能称强度泛化，不能称未知机制。
- 只改善校准或拒判：不满足主要“完整覆盖真假判别提升”目标，应如实定位。
